# Ideas

This is the future-looking backlog. These are not all immediate tasks.

## Near-Term Product Ideas

- Add approval and rejection emails back to coaches after owner review.
- Add a visible owner badge or pending count in more places for faster owner workflow.
- Make the client detail back button smart so it returns to the roster when opened from `/coach/clients/roster`.
- Add pagination or incremental loading if coaches start managing large rosters.
- Add a compact `recently viewed clients` area for coaches.

## Phase 2 Ideas

- Nutrition compliance dashboard for coaches.
- Weekly check-in wizard for clients.
- Meal plan builder for coaches.
- Progress photo uploads and comparison view.
- Automated reminder system for check-ins and missed activity.

## Monetization Ideas

- Keep early beta access controlled rather than fully open.
- Add pricing only after the onboarding, approval, and coach workflow feel stable.
- Likely pricing path:
  - free or manual beta access at the start
  - paid coach plan later
  - advanced nutrition/accountability features behind a higher plan

## Operations Ideas

- Add a simple owner analytics view:
  - total approved coaches
  - pending coaches
  - total clients across the platform
  - average clients per coach
- Add a coach detail page in owner view showing all clients assigned to that coach.
- Add audit notes for owner approvals and rejections.

## UX Ideas

- Add saved filters or default views on the client roster.
- Add quick status summaries like `No plan`, `Inactive`, and `Check-in overdue` in the coach navbar or dashboard.
- Add inline success toasts instead of only static feedback blocks.
- Add empty-state illustrations or more polished empty states once the workflow is stable.

## Longer-Term Ideas

- Stripe billing for coach subscriptions.
- Invite links for coaches to onboard clients more smoothly.
- In-app notifications center for reminders and approvals.
- Optional AI assistant once costs and clear use cases justify it.
